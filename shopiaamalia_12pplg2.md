1 Keuntungan utama dari pembatasan atau pelarangan commit langsung ke branch main adalah menjaga stabilitas dan keandalan sistem produksi (production stability). manfaat pembatasan branch adalah Menghindari error, bug fatal, atau konflik kode yang dapat merusak,Memungkinkan proses peninjauan code melalui Pull Request leh ketua tim atau rekan kerja sebelum kode digabungkan, Setiap anggota tim dapat bekerja secara terisolasi pada feature branch masing-masing tanpa saling mengganggu progres pekerjaan anggota lain.
Untuk memulai pengerjaan, langkah pertama adalah memastikan posisi berada di branch utama (main) dengan menggunakan perintah git checkout main, lalu menjalankan git pull origin main untuk mengambil serta menyinkronkan pembaruan terbaru dari repositori pusat di GitHub ke komputer lokal. Setelah itu, buat dan langsung pindah ke branch fitur baru menggunakan perintah git checkout -b jawaban-shopia_XI agar pekerjaan tetap terisolasi dengan aman tanpa mengganggu branch utama. Jika file jawaban (shopia_XI.md) sudah selesai dibuat di dalam folder proyek, jalankan perintah git add shopia_XI.md untuk mendaftarkan file tersebut ke dalam staging area Git. Selanjutnya, simpan perubahan secara permanen di komputer lokal menggunakan perintah git commit -m yang dilengkapi dengan pesan deskriptif sebagai catatan riwayat pekerjaan. Langkah terakhir adalah mengunggah branch fitur beserta seluruh riwayat commit ke GitHub dengan perintah git push -u origin jawaban-shopia_XI
